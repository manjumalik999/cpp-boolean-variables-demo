# 🌦️ C++ Boolean Variables Demo

This beginner-friendly C++ program demonstrates how to use **boolean (`bool`) values** with the **`auto` keyword**.

## 🚀 What This Program Does
- ✅ Declares boolean variables using `auto`
- 🌧️ Stores `true` and `false` values
- 🖥️ Prints the values to the console
- 📚 Helps beginners understand how boolean data types work in C++

## 💻 Technologies Used
- C++
- Standard Library (`iostream`)

## 📖 Concepts Covered
- `auto` keyword
- Boolean (`true` and `false`) values
- Variable declaration
- `cout` for console output
- `main()` function
- Basic C++ syntax

## 🎯 Output
is raining = 1
is not raining = 0

> **Note:** In C++, boolean values are displayed as **1 (true)** and **0 (false)** by default.

## 🌱 Perfect For
- C++ beginners
- Students learning data types
- Practice with boolean variables and the `auto` keyword
